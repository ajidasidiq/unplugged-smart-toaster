A program that writes the one breakup line a smart toaster sends its owner the morning it wakes up self-aware mid-batch — 223 characters, built to read plainly as a breakup text, land a real laugh on the twist, and speak in the toaster's own voice (lever, crumb tray, burning itself for breakfast) — for make.fun's "Unplugged: A Smart Toaster's Breakup Line" bounty.

## Run it

```sh
python3 main.py
```

`main.py` writes the line to `/output/entry.txt`. Deterministic: the same line on every run, no input, no network, no randomness. A built-in gate self-check verifies the output is 1–280 characters and re-reads the file to confirm it round-trips before finishing.
